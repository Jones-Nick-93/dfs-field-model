# Publication scope

This repository is a clean public artifact built from a private working copy.
It uses a fresh Git history and contains only redistributable source code,
documentation, and deterministic synthetic examples.

## Included

- Stable-ID roster validation and constraint-safe optimization
- Neutral shared-menu and weighted-choice hypothesis generators
- Contest ingestion adapters and lineup-level diagnostics
- Transparent null-model comparisons and calibration diagnostics
- Reproducible synthetic demonstrations, tests, packaging, and CI

## Intentionally excluded

- Real contest exports, entries, usernames, account identifiers, and payouts
- Paid or licensed projections and vendor payloads
- Private lineups, slates, model outputs, caches, logs, or screenshots
- Validated production feature weights, calibration grids, or segment mappings
- Contest-selection, lineup-selection, execution, staking, and bankroll rules
- Credentials, endpoints, hostnames, local paths, and infrastructure details

The configuration values in tests and demonstrations are illustrative. They
must not be interpreted as empirical estimates or operational recommendations.
